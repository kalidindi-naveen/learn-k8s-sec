Secure Ingress
--------------
curl <IP> -kv
-k -- skip certificate validation [not disable encryption]
-v -- show detailed information [DNS, TLS, req,...]

CSR: Certificate Signing Request
CA: Certificate Authority
SSL: Secure Sockets Layer
TLS: Transport Layer Security

### Generate Certificate: [cert.pem, key.pem]
root@controlplane:~$ openssl req -x509 -newkey rsa:4096 -keyout key.pem -out cert.pem -days 365 -nodes

Steps:
------
Purchase SSL/TLS Certificate – Choose an SSL/TLS provider (CA)
Generate Private Key + CSR – key.pem + request.csr
Submit CSR to CA – Send request.csr to the provider
CA Issues Certificate – Receive cert.pem + chain.pem
Create Kubernetes TLS Secret – Store certificate and private key as tls.crt + tls.key
Configure Ingress TLS – Reference the Secret using spec.tls[].secretName

### Implementation
root@controlplane:~$ k run fe --image nginx
pod/fe created
root@controlplane:~$ k expose pod fe --port 80
service/fe exposed

root@controlplane:~$ vi ing-tls.yml
apiVersion: networking.k8s.io/v1
kind: Ingress
metadata:
  name: tls-step-into-iot
spec:
  ingressClassName: nginx #`*****`
  tls:
  - hosts:
      - step-into-iot.cloud
    secretName: step-into-iot
  rules:
  - host: step-into-iot.cloud
    http:
      paths:
      - path: /
        pathType: Prefix
        backend:
          service:
            name: fe
            port:
              number: 80

root@controlplane:~$ k apply -f ing-tls.yml 
ingress.networking.k8s.io/tls-step-into-iot created
