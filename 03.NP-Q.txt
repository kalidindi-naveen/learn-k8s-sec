One of the nginx based pod called cyan-pod-cka28-trb is running under cyan-ns-cka28-trb namespace and it is exposed within the cluster using cyan-svc-cka28-trb service.
This is a restricted pod so a network policy called cyan-np-cka28-trb has been created in the same namespace to apply some restrictions on this pod.
Two other pods called cyan-white-cka28-trb1 and cyan-black-cka28-trb are also running in the default namespace.
The nginx based app running on the cyan-pod-cka28-trb pod is exposed internally on the default nginx port (80).
Expectation: This app should only be accessible from the cyan-white-cka28-trb1 pod.
Problem: This app is not accessible from anywhere.
Troubleshoot this issue and fix the connectivity as per the requirement listed above.

##### Setup Script:
#!/bin/bash

# Create namespace
kubectl create namespace cyan-ns-cka28-trb --dry-run=client -o yaml | kubectl apply -f -

# Create nginx application pod
kubectl run cyan-pod-cka28-trb \
  -n cyan-ns-cka28-trb \
  --image=nginx \
  --labels="app=cyan-nginx" \
  --port=80

# Create service
kubectl expose pod cyan-pod-cka28-trb \
  -n cyan-ns-cka28-trb \
  --name=cyan-svc-cka28-trb \
  --port=80 \
  --target-port=80

# Create white client pod
kubectl run cyan-white-cka28-trb1 \
  --image=curlimages/curl \
  --labels="app=cyan-white" \
  --command -- sleep 36000

# Create black client pod
kubectl run cyan-black-cka28-trb \
  --image=curlimages/curl \
  --labels="app=cyan-black" \
  --command -- sleep 36000

# Wait for pods
kubectl wait --for=condition=Ready pod/cyan-pod-cka28-trb \
  -n cyan-ns-cka28-trb --timeout=120s

kubectl wait --for=condition=Ready pod/cyan-white-cka28-trb1 \
  --timeout=120s

kubectl wait --for=condition=Ready pod/cyan-black-cka28-trb \
  --timeout=120s

# Create intentionally broken NetworkPolicy
cat <<'EOF' > np.yml
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: cyan-np-cka28-trb
  namespace: cyan-ns-cka28-trb
spec:
  podSelector:
    matchLabels:
      app: cyan-nginx
  policyTypes:
  - Ingress
  - Egress
  ingress:
  - from:
    - namespaceSelector:
        matchLabels:
          kubernetes.io/metadata.name: default
      podSelector:
        matchLabels:
          app: cyan-white-wrong
    ports:
    - protocol: TCP
      port: 80
  egress:
  - to:
    - ipBlock:
        cidr: 0.0.0.0/0
    ports:
    - protocol: TCP
      port: 80
EOF

kubectl apply -f np.yml

echo "Setup completed!"
