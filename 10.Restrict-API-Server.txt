Static pods??
-------------
A Static Pod is managed directly by the kubelet on a specific node, using a YAML manifest stored on that node.
- No Deployment or ReplicaSet required.
- Kubelet creates and monitors it.
- Typically used for control-plane components.

root@controlplane:~$ cd /etc/kubernetes/manifests/
root@controlplane:/etc/kubernetes/manifests$ ls
etcd.yaml  kube-apiserver.yaml  kube-controller-manager.yaml  kube-scheduler.yaml

Ex: No Deployment, ReplicaSet, or scheduler is required to manage the Static Pod.
1. You create a Pod YAML file on a node (usually in /etc/kubernetes/manifests/).
2. The kubelet monitors this directory.
3. The kubelet reads the manifest and creates the Pod.
4. The Pod runs on that node.
5. If the Pod crashes, kubelet attempts to recreate it.
6. If you remove the manifest file, kubelet terminates the Pod.

Scenario-2:
-----------
The insecure serving port was deprecated and removed in Kubernetes 1.20.

In modern Kubernetes versions
- --insecure-port is no longer supported.
- You don't need to add --insecure-port=0 for disable the insecure port.
- API server communication uses the secure HTTPS endpoint, typically port 6443.
